# 可选程序化配乐源码

保留固定种子的程序化合成和母带处理源码，不附带任何原包 WAV 或旧音频验收记录。原包音乐来源声明与发布者的抖音来源说明不一致，所有音频二进制按发布者要求排除。

可自行准备有合法使用权的 150 秒配乐，保存为本目录 `soundtrack_150s.wav`，供 `../render_all.py` 使用。

可选安装 NumPy / SciPy 并运行 `python3 v3/audio/render_audio.py`，从合成代码生成新的音频与 QA。该流程本次只检查了语法，未执行完整音频生成。FFmpeg 还需支持脚本使用的 `soxr` 重采样器及 `loudnorm`、`alimiter` 过滤器。

生成的音频、音频 QA 和私人音乐文件不会进入公开发布包。
